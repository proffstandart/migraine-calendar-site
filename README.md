# Календарь мигрени — лендинг

Статический сайт приложения «Календарь мигрени» для GitHub Pages.

- `index.html` — мультиязычный лендинг: русский, английский, немецкий, французский, испанский и китайский.
- `privacy.html` — политика конфиденциальности на русском и английском.
- `img/` — иконка и реальные скриншоты приложения.

Сайт не использует внешние шрифты, аналитику, рекламу, cookie или серверную часть. Выбранный язык сохраняется только в `localStorage` браузера.

## Локальный запуск

```bash
npm install
npm run dev
```

Аргументы Vite передаются через `--`, например:

```bash
npm run dev -- --host 127.0.0.1 --port 7100
```

Для публикации используется содержимое корня репозитория, сборка не требуется. В GitHub Pages выберите ветку `main`, папку `/ (root)`.
